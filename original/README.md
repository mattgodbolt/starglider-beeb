# The originals

*Starglider* (Rainbird, 1986), every version found, as preserved by
archive.org's TOSEC sets and software library and by
[Spectrum Computing](https://spectrumcomputing.co.uk/entry/4863/) (ZXDB
entry 4863). Nothing here but this file and `SHA256SUMS` is committed: the
images, scans and text are not ours to redistribute.

    make fetch      # tools/fetch_original.sh: download them and check them

| File | What it is |
|---|---|
| `st/Starglider (1987)(Rainbird).st` | Atari ST, Argonaut Software (Jez San), "Completed, Sept 1986". TOSEC's clean image: `AUTO/STAR.PRG` holds the code, the shapes, the samples and the speech in one file; `TITLE.TRA` and `RESULT.TRA` are the title and score screens |
| `st/Starglider (1987)(Rainbird).stx` | The same disc as a Pasti image of the protected master |
| `st/Starglider (1987)(Rainbird)[m EMT].st` | A crack by GMC and TUC. Its `STAR.PRG` differs from the clean one in 47 bytes, its credits; it adds pictures (`FIL1`-`FIL8`, `PRES`, `EDIT1.PIC`) and its own `STRIP.PRG` |
| `amiga/Starglider (1987)(Rainbird).adf` | Amiga, Argonaut's own port of the ST |
| `zx/Starglider128.tap`, `zx/Starglider48.tap` | ZX Spectrum, Realtime Games (Ian Oliver, Graeme Baird; music David Lowe). The 128K adds Clare Edgeley's speech and the special missions |
| `zx/Starglider - Release n - Side s.tzx` | Three releases of the Spectrum tape |
| `zx/Starglider (+3).dsk` | The Spectrum +3 disc |
| `zx/Starglider128.z80` | A 128K snapshot from archive.org's Spectrum library |
| `zx/Starglider.txt`, `zx/Starglider(EN).pdf` | The manual |
| `zx/Starglider(EN)_novella.pdf` | James Follett's novella, which came in the box |
| `zx/Starglider_map.jpg`, `zx/Starglider_KeyboardMap.jpg`, `zx/Starglider.gif`, `zx/Starglider.scr` | A map, the key guide, an in-game screen, the loading screen |
| `cpc/Starglider.dsk` | Amstrad CPC, Realtime Games |
| `c64/Starglider.d64` | Commodore 64, Solid Image |
| `apple2/Starglider.do` | Apple II, Solid Image |
| `pc/Starglider_1986.zip` | IBM PC (CGA), Realtime Games |
