# The object handlers' mines once "LEVEL 1" is over, on the keys, the
# player held still and teleported: in a mine's warning zone, then close
# enough to set it off with the shields full; then in front of another,
# a type-3 object drawn beyond it, and docked ($2CA set), where neither
# the mine nor the lasers act on the lists the last flight step left.

# mine 87 (x &4F70, y -1040, z &DC60), 1,792 ahead
debug w w $12206 0

debug w w $5c03c 0

# ... then 1,024 ahead
debug w w $5c02e $4f70 $fbf0 $d860
