# The object handlers on level 3's rules (the level variable $296 set on
# level 1's layout): StarGlider One's homing missiles and the pyramid

# player high (y -1790), where homing missiles go off; then a tank near,
# and two silos' and two tanks' counts set to run out (a reload, a
